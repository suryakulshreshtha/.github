# Support

These are personal projects maintained in spare time. There is no support
contract, but questions are welcome.

- **Something is broken** — open an issue on that repository with the failing
  command and its full output.
- **A test is flaky** — use the *Flaky test* issue template. It asks for the
  node ID and observed failure rate, which are the two things that make a flaky
  report actionable.
- **A question about how something works** — open a Discussion if the repository
  has them enabled, otherwise an issue is fine.
- **A security problem** — see [SECURITY.md](SECURITY.md). Do not open a public
  issue.

Before filing, please say which repository, which commit, and what you expected
to happen. "It does not work" costs a round trip that a command and its output
would have saved.
